
# Task 4 – Network Programming and IPC

## Description

This project implements a TCP client-server application demonstrating inter-process communication.

## Features

- TCP socket communication
- Client-server architecture
- Multiple concurrent clients
- User authentication
- Message exchange protocol
- Error handling
- Connection management

## Compilation

```bash
make
```

## Run Server

```bash
./server
```

## Run Client

```bash
./client
```
