# Task 2 – Memory Management Simulation

## Description

This program simulates virtual memory management using paging and page replacement algorithms.

## Features

- Configurable page size
- Configurable number of page frames
- FIFO page replacement
- LRU page replacement
- Page fault tracking
- Hit and fault ratio calculation
- Memory allocation visualization

## Compilation

```bash
make
```

## Run

```bash
./task2
```

## Output

The program displays:

- Frame allocation
- Page hits
- Page faults
- Hit ratio
- Fault ratio
