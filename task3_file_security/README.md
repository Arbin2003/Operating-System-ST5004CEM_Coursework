# Task 3 – File System Operations and Security

## Description

A secure file management system implemented in C.

## Features

- User authentication
- File creation
- File reading
- File writing
- File deletion
- File permission management
- File encryption and decryption
- Audit logging

## Compilation

```bash
make
```
