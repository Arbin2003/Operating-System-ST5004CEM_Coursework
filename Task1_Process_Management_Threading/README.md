# Task 1 – Process Management and Threading

## Description

This program demonstrates process management and multithreading concepts using POSIX threads in C.

## Features

- Creates multiple concurrent threads
- Thread synchronization using mutexes
- Round-robin scheduler simulation
- Race condition demonstration
- Deadlock prevention

## Compilation

```bash
make
```

## Run

```bash
./task1
```

## Output

The program demonstrates:

- Thread execution
- Shared counter synchronization
- Race condition without mutex
- Synchronization using mutex
- Round-robin scheduling
- Deadlock prevention
